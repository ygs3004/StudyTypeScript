# TypeScript 컴파일러

- tsc app.ts -w (watch mode, 파일이 변할때 watch 컴파일)
- tsc --init (tsconfig.json 생성 및 관리)
- tsc (ts init 후 tsconfig 기중 해당 폴더 컴파일)
- tsc -w (ts init 후 tsconfig 기중 해당 폴더 watch 컴파일 )


# tsconfig.js
- excluded: [제외할 파일] 
- node_modules 는 기본적으로 excluded 되어있으나 명시적으로 키 값을 추가할 시 제외되지 않으므로 추가하여 제외시킨다.
- include: [포함할 경로]
- files: [포함할 파일]
